# BizEvolve website

One-page static website for BizEvolve: websites for local businesses, live in 7 days.

- Open `index.html` through a web server: `node tools/serve.js 8080`, then http://localhost:8080
- Edit business details in `js/config.js`
- Full notes (decisions, editing, reviews, publishing): see [NOTES.md](NOTES.md)
